# シナリオ骨組み（v0.1）

天音ハル 恋愛シミュレーション ／ プレイ時間 10〜15分

---

## 0. 基本ルール

### 好感度
- 開始値 0、上限 100
- 選択肢の種類ごとの基本値

| 種類 | 基本値 | 備考 |
|---|---|---|
| 💗 好印象 | +10 | 気分補正 ±3 |
| 🙂 普通 | +3 | |
| 💀 ダメ | -10〜-20 | 「好感度 -15」ポップ＋SEで笑いに変える |
| 🤪 ギャグ | -5〜+5 | 気分「ご機嫌」なら +5〜+8 になることも |
| ☠️ 一発アウト | 即エンド | 出現率 30%（場面ごとに調整） |

### 分岐ゲート
| タイミング | 条件 | 未達時 |
|---|---|---|
| 章1 → 章2 | 好感度 30以上 | リスナーエンド |
| 章2 → 章3 | 好感度 60以上 | 友達エンド（相談相手のまま） |
| 告白 | 好感度 85以上 | 友達エンド（「ごめん、まだ…」） |

全場面で 💗 を選ぶと：章1終了 50 → 章2終了 90 → 告白前 100（上限）。
💗 を2〜3回外しても恋人エンドに届く余裕を持たせる。

### 呼び方の変化
| 状態 | 呼び方 |
|---|---|
| 章1 | 「リスナーさん」→ コメント読まれ後は「（ハンドル名）さん」 |
| 章2 | 「（ハンドル名）さん」→ 好感度75以上で「（ハンドル名）くん」 |
| 章3 | 本名を聞いた後は名前呼び。恋人エンドで呼び捨て |

### その日の気分（各章の冒頭で抽選）
| 気分 | 効果 | 匂わせ方 |
|---|---|---|
| ☀️ ご機嫌 | 🤪 がウケやすい | 「今日なんかテンション高いかも！」 |
| 😪 眠い | 長文に反応が薄い／甘い言葉 +3 | あくび、まばたきが遅い |
| 🔥 テンション高 | からかい系 +3／重いコメント -5 | 早口、身振りが大きい |

### 選択肢の抽選ルール
- 1場面につき候補プールから **3つ** 表示（場面によって4つ）
- 💗 を必ず1つ含める
- ☠️ は出現率で判定。出たら残り枠の1つを置き換える
- 表示順はシャッフル
- 反応は候補ごとに 2〜3 パターンからランダム

## プロローグ

- 深夜、なんとなく開いた配信サイトで「天音ハル」の雑談配信を見つける
- **ハンドル名入力**（コメントに表示される名前）

隠し反応（入力された名前による）
| 入力 | 反応 |
|---|---|
| 「ハル」「天音ハル」 | 「え、わたし！？ なりすまし！？」→ 名前を入れ直させる |
| 空欄 | 自動で「名無しのリスナー」 |
| 極端に長い名前 | 「名前長っ！ 寿限無！？」 |
