# シナリオ骨組み（v0.2）

推しVTuberを落とせ！ ／ プレイ時間 25〜35分

v0.1 からの主な変更（2026-11-07 合意）
- 主人公は「DMを狙う人」ではなく、純粋に配信を楽しむ深夜のリスナー。DMは本当のサプライズ
- 好感度は DM が届くまで非表示。代わりに人気（同接・登録者）が見える
- 回答で **人気** と **性格**（天使／女王様／芸人）が変わる
- 3章 → 5章構成（バズ編・デート編を新設）、場面は 13 → 31、エンドは 16 → 26

## 0. パラメータ

| パラメータ | 表示 | 増え方 |
|---|---|---|
| 💗 好感度（0〜100） | 第三章の DM 到着まで非表示 | 選択肢の種類（下表）＋性格補正 |
| 📈 人気（0〜100） | 同接・登録者数として常に表示 | コメントの傾向（😇+1 / 💰+4 / 🎤+2）、バズ・レイドなどのイベント |
| 🎭 性格 | 非表示（セリフで分かる） | 章の終わりに、その章で多かったコメントの傾向で決まる（2票差以上で切り替わる） |

### 選択肢の種類（好感度）
| 種類 | 好感度 | 備考 |
|---|---|---|
| 💗 好印象 | +6 | |
| 🙂 普通 | +2 | |
| 💀 ダメ | -15 | |
| 💣 地雷 | -8 | 良さそうに見えて重い・押しつけがましい |
| 🤪 ギャグ | 0〜+5 | 選択肢ごとに設定 |
| ☠️ 一発アウト | 即エンド | 出現率 30% |

### コメントの傾向 → 性格
| 傾向 | 何が該当するか | 性格 | 性格の好み（好感度補正） |
|---|---|---|---|
| 😇 やさしい | 💗・🙂 | 天使ハル（初期） | 😇 +2 |
| 💰 貢ぎ | スパチャ・メンバーシップ・プレゼント | 👑 女王様ハル | 💰 +4、😇 -2 |
| 🤪 ネタ | 🤪 | 🎤 芸人ハル | 🤪 +5、ネタ告白でも好感度90でOK |

- 選択肢は1場面に **5つ**：💗・🤪・💰・💣 を1つずつ（あれば）、☠️ は 30%、残りはランダム
- 配信画面では、5つのうち1つは必ず「ネタ枠」のコメント（`spice`）：
  ネットミーム 🤪（50%）／小学生レベルの下ネタ・胸いじり・キモいコメント 💀（40%）／一線を越えたセクハラ ☠️ → 🚫セクハラBANエンド（10%）。
  ミームはVTuber系（てぇてぇ・ガチ恋距離・中の人などいない・ママ見てる〜？・切り抜き班・初見です（毎日来てる）・ASMRはよ）も含む。
  キモ・下ネタ系を3回選ぶと 🧊オタク見下しエンド（2回目でハルが警告）。
  露骨な文面は書かず「（ここには書けない下ネタ）」のように表現する。芸人ハルは小学生ネタに少し甘い
- 性格が変わると、次の章の冒頭でナレーションが入る（「最近のハルは……」）
- セリフは `by` で性格ごとに差し替え（例：初見さんへのあいさつ、悩み、告白の返事）

### リアルの性格（ひなの）
配信の性格とは別。最初は 🌱人見知り。4-4 と 5-2 の終わりに、それまでの選択の傾向で変わる（2票以上かつ単独トップ、同数なら😇が優先）。

| 性格 | 傾向 | 好み（好感度補正） | 特徴 |
|---|---|---|---|
| 🌱 人見知り | （初期） | なし | まだ言葉を選んでいる |
| 🍓 甘えんぼ | 😇 やさしい | 😇 +2 | 袖をつまむ・手をつなぐ・「おやすみ」が長い |
| 📒 しっかり者 | 💰 貢ぎ | 😇 +2、💰 -2 | 割り勘・家計簿チェック・おごると怒る（でも喜ぶ） |
| 😈 いたずらっ子 | 🤪 ネタ | 🤪 +4、ネタ告白でも好感度90でOK | 尾行・クイズ・からかい |

- セリフは `by` で差し替え（`by` はリアルの性格 → 配信の性格の順に探す）、場面は `variantBy: "real"`、条件は `real` / `notReal`
- 恋人エンド・逆告白エンドに、リアルの性格ごとの一言が入る
- デート・DM・通話はハルの配信ではないので、人気（同接・登録者）は変わらない（変わるのは配信中のコメントだけ）
