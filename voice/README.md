# ハルのボイス

ここに音声ファイルを置くと、ハルが笑ったり驚いたりしたセリフで自動的に再生されます。
ファイルがないボイスは鳴らないだけなので、少しずつ増やしていけます。

## 録音リスト

| ファイル名 | セリフ | 鳴る表情 |
|---|---|---|
| `laugh_1.mp3` | ふふっ | にっこり・リラックス・ドヤ顔 |
| `laugh_2.mp3` | えへへ | 〃 |
| `laugh_3.mp3` | あはは | 〃 |
| `surprise_1.mp3` | わっ | びっくり |
| `surprise_2.mp3` | えっ！？ | 〃 |
| `panic_1.mp3` | ひゃっ | あわあわ |
| `panic_2.mp3` | わわっ | 〃 |
| `shy_1.mp3` | えへへ… | 照れ |
| `shy_2.mp3` | うぅ… | 〃 |
| `angry_1.mp3` | むぅ | 怒り |
| `sad_1.mp3` | はぁ… | しょんぼり |

同じ表情のファイルが複数あるときは、その中からランダムに1つ鳴ります。

## 録音のコツ

- 形式は **mp3**（iPhoneでも確実に鳴るため）。1つ 0.3〜1.5秒くらい
- 前後の無音はカットし、音量は全ファイルでそろえる（ピークが -3dB 前後）
- モノラル・44.1kHz で十分です

## 調整（`data/scenario.json` の `"voice"`）

- `rate`: 表情が変わったときに鳴る確率（0.6 = 60%）
- `cooldownMs`: 一度鳴ったあと、次に鳴れるまでの時間（ミリ秒）
- `byFace`: どの表情でどのボイスを鳴らすか
- `clips`: ボイスの種類と、それぞれのセリフ（並び順がファイル番号 `_1`, `_2` …）
- 個別のセリフで `"voice": "laugh"` と書くと必ず鳴り、`"voice": false` と書くと鳴りません
